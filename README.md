# 公文排版工作台

面向日常办公的 Windows 公文排版工具。本仓库用于发布可下载版本、使用说明和更新记录；项目源码单独维护。

## 当前状态

正式发行版正在整理，当前尚无可推荐下载的正式版本。请以本仓库 Releases 中明确标注的正式版本为准。

2026-09-05：2.0 测试版已完成首批修复及本地候选包验证，包括导出结果提示、失败保护、Word 原始结构保留和后台导出。当前尚未上传可下载的软件包；仍需完成第三方分发材料核对、独立电脑验收及更新机制。

## 使用与更新

发行包将提供中文操作说明、适用系统、版本号和已知限制。单位网络无法联网更新时，可使用离线更新包。具体能力以已发布版本说明为准。

自动更新尚未实现。测试阶段采用完整包解压到新目录、保留旧版目录的人工更新方案；不要覆盖正在运行的程序，也不要将个人文档存放在程序目录。

## 反馈问题

请提供软件版本、Windows 版本、复现步骤、预期结果与实际提示。不要公开上传单位内部公文、个人信息、真实文件路径或未脱敏的截图。可用虚构内容制作最小复现样例。

## 字体

正式基础包不附带再分发授权尚未确认的字体。所需字体及缺失时的处理方式将在版本说明中列明。
